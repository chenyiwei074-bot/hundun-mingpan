# hundunmp.vip 界面方案（可施工版）· 2026-10-22

对象：`frontend/`（Next.js + Tailwind v4，设计令牌全在 `app/globals.css`）。
本文只定**结构与状态**，实现分三批（§13）。静态稿在 `docs/design/mock/`，不在生产路由上：
`docs/` 在 `frontend/` 之外，不在 Tailwind v4 的自动扫描目录里，类名一律 `mk-` 前缀且不用工具类做双保险 ——
**实测**：带稿子重建后，产物 CSS（唯一一个包，65,846 字节）里 `mk-` 命中 0 次，构建路由表里没有 `docs` 相关条目。

三条不可退的纪律：① 两栏体系选择是**主要内容**，不是页角开关；② 状态真实（未开放不许伪装成可用）；
③ AI 只理解需求与解释象义，**排盘/卦象/几何判定一律由工具算**，界面必须把这两类分开。

## 3. 门廊规格

**栅格**：`.mk-gate{display:grid;grid-template-columns:1fr 1fr;min-height:100dvh}`，中缝 1px；
≤640px 改单列，每栏 `min-height:56dvh`。品牌带高 ≤88px，不吃两栏面积。

**每栏是一个 `<a class="mk-panel">`**：栏内**禁止再嵌 `<a>` 或 `<button>`**（计数行、说明、图形全是文字/装饰），
命中区整块 ≥44px；键盘 `Tab` 直接落到整栏。

| 元素 | 东方栏 | 西方栏 |
|---|---|---|
| 底 | `#f5f2ea` + 纸纹（`feTurbulence` baseFrequency .65 / numOctaves 3 / **opacity .03**） | `#1b1030` + 星点（radial-gradient，最大不透明度 .18） |
| 装饰（各只一种主体 + 一种配角） | 墨块 `linear-gradient(158deg,#19191c,#23201a 55%,#2c2519)` 承托标题；山脊线 `stroke rgba(29,29,31,.18)` 1px | 黄道环 1px `rgba(230,220,255,.14)`；月相三格（弦/望/朔） |
| 标题 | 「东方玄学」44px 衬线 600，`#1d1d1f` | 「西方玄学」44px 衬线 600，`#f3eeff` |
| 说明 | 从八字、六爻到风水，在传统体系中寻找问题的脉络。 | 从占星、塔罗到数字象征，探索不同的自我理解方式。 |
| 提示行 | 「进入东方世界 →」15px `#b23a2e`（5.31:1） | 「进入西方世界 →」15px `#d9b877` |
| 计数行 | 「已开放 8 / 10 项 · 部分可用 1 · 未开放 1」13px `#5f5f66` | 「已开放 0 / 5 项 · 未开放 5」13px `#c9bfe0` |

禁：符咒、龙凤、廉价金框、闪烁、粒子爆发、复杂入场；装饰不得压过文字（纹理层 `pointer-events:none` + 独立低透明度）。

**三态**（§静态稿里同一文件带 default / hover / focus 三条并排）：
- `hover` / `active`：叠加层 `::after{background:#fff;opacity:.045}`（西栏用 `#d9b877` `opacity:.06`）+ 文案块 `translateY(-2px)`，180ms `ease-out`。
  **不用 `filter:brightness()`** —— 它会改合成色而骗过 census 的取值式对比度读取（§7 的判据读声明不读渲染值）。
- `focus-visible`：`outline:2px solid` + `offset:2px`；亮底用 `#7a5f31`，墨底用 `#e3cd96`（实测 11.55:1，远超 3:1）。
- `prefers-reduced-motion:reduce`：位移与过渡归零，叠加层保留但 `transition:none`（globals.css:845 已是 `*` 级）。

## 5. 西方工作页规格

同骨架、同组件、同导航秩序，**只换主题令牌**（`[data-mode="western"]` 重指令牌，不重写规则 —— 现状已如此，保持）。
H1「你想从哪个角度开始？」副「提出你的问题，或选择一种西方玄学工具继续探索。」

## 6. 问事框组件状态机

```
empty ──输入──> ready ──Enter / 点「开始分析」──> thinking ──┬─> matched(1)   一个入口：进入 · X
                                                            ├─> choices(n)   并列 chip 让用户挑，不代选
                                                            ├─> clarify      缺出生时间/出生地/起卦方式/朝向 → 就地给补料入口
                                                            └─> closed       命中未开放：说明缺什么 + 不伪装
```
- 多行 `textarea` 4 行起，自增高 ≤8 行；`Enter` 发送、`Shift+Enter` 换行；**IME 门闩**：`compositionstart` 起、`compositionend` 止，期间 Enter 不发送（中文输入最容易误发）。
- `thinking` 只写「在想…」+ 按钮禁用；**不给假进度**（`/api/assistant` 真的没有耗时数据可报）。
- 结果区高度预留（沿用 `.qa-pane` absolute-inset 的做法），插入答案不得推走任何已有元素 → 交互后 CLS = 0。
- 来源标注二选一，不得混：走本机 → 「这一轮由本机目录匹配给出，未经模型」；真走服务端才允许「这一轮来自服务端路由」。
  修好 §12① 之后这条才是可验证的；`degraded`（含超时/404/形状不合）原文要显示成一行 13px 说明，**不许静默回落**。

## 8. 户型流程（分步 + 隐私出口）

步条常驻：`① 选图或手绘 → ② 定朝向 → ③ 标房间/门窗 → ④ 说你最在意什么 → ⑤ 结果与图上依据`。
- ①：`选户型图` / `手工画` / `样例`；新增 **`移除这张图`**（二次确认 → 清 image、几何、候选，回步骤①）。
- ②：三 chip `朝南 / 朝北 / 朝向未确认`；未确认时结果段必须明写"未据朝向判定"。
- ③：房间名称与用途 chips、加门/加窗/删墙；0 门窗 → 提示「请手动补门窗」。
- ④：关心点 chips（采光 / 动线 / 睡眠 / 工作区），可跳过；这四项只影响"讲哪几段"，不改判定。
- ⑤：`规则 / 结论 / 依据 / 说不准的 / 没判定的部分` 五段；依据带图上标号。确认门保留：未确认不得出结论。
- 隐私：同意框现有两句（不进入报告/回执/公开台账、按本人标识可取、7 天自动删）保留，并**在①与步条上各复现一次**（一句话，不弹窗）。原图/生辰/完整提问永不上链。

## 9. 结果页与凭证

五区固定：`结论` → `计算所得`（表格/等宽 + 口径戳）→ `AI 解释（象义，非计算）` → `依据与出处` → `可以继续追问`。
底部两个次级动作：`保存/我的报告`、`查看记录凭证`；凭证四态文案不改（`未提交 / 未锚定 / 等待锚定 / 状态未知`），
**任何新页面上都不许出现**「已上链 / 无法伪造 / 绝对可信」。验真页仍是纯本地比对，不要求 id。

## 10. 验收线（每批都要绿）

44px 绝对下限（含整栏 anchor）、按钮 min-height 46、正文 AA 4.5:1 / 大字 3:1 且不可豁免、焦点环可见（两种底分别验）、
`prefers-reduced-motion` 全量归零、375px 无横向溢出、加载期 CLS ≥0.1 记 warn、交互后 ≥0.1 记 fail、
门廊两栏与两工作页各加 harness 态（含"答完之后"那一态），**文本比较类断言一律先剥注释**（`tools/_lib/codesrc.ts`），
新增断言必须自带证伪。
死文件清理（**实测改正我先前那句"正被扫描污染进包"——它不成立**）：`app/qingnang-full.css` 与 `public/qingnang.css`
（各 300,089 字节，含 `[data-theme=zen]`）在源码里**零引用**（grep tsx/ts/css/js 无一处 import 或 link），
本次重建产物只有一个 CSS 包 65,846 字节，里面 `data-theme=zen` **0 命中**、静态稿的 `mk-` **0 命中**；
`app/page_bak_20261015_visual.tsx` 的 184 个类名 token 也全部与在用代码重合，没有独有候选。
所以删它们的理由不是"包变大了"，而是：① `public/` 那份挂在生产域上可被 `/qingnang.css` 直链下载，
是一份没人引用的 300KB 样式表；② 它们与 `app/*_bak*` 都落在 Tailwind v4 的自动扫描目录内（`docs/` 在 `frontend/`
之外，本次实测不进扫描 —— 这也是静态稿放 `docs/design/mock/` 并用 `mk-` 前缀的原因），留着等于给后续改版
留两份互相矛盾的令牌源；③ 读代码的人会把死令牌当成活的。**census 那条守卫照加**：产物里出现 `[data-theme=zen]`
即判红 —— 它今天就是绿的，作用是咬住"有人把 zen 主题重新引回来"。

④ 悬停用叠加层 `opacity`，禁 `filter:brightness()`。
