# docs/classics —— 本站引文的比对底本

这里只放**逐字入仓的古籍原文**，供页面引用与 `tools/scenario-acceptance` 做子串比对。
它不是知识库、不是笔记，任何改写、串接、节选拼接都不许发生 —— 一改就不是底本了。

## 收录规则

1. **只收公版原文**。不取现代注释、白话译文、今人整理本的转述。
2. 每份文件必须带全九项元数据：书名／卷篇／**转引关系**／版本／取文方式／抓取日期／
   繁简与标点处理／比对规则。缺任一项就不算可核。
3. **转引要写清**。例：《三命通會》卷五的那句宫分文是《三命通會》**引《秘訣》**，
   页面署名只能署《三命通會》卷五引《秘訣》，不能署《秘訣》原文 —— 《秘訣》没有独立可核全文。
4. **繁简与标点原样保留**。维基文库部分页面繁简混排（《渊海子平》论伤官一段即如此），
   不做转换；四库本常无标点连写，比对一律走无标点那串，加标点版只供阅读。
5. 页面引文必须是本目录某份文件的**连续子串**。要引两段，就分两处引，不许删中间内容拼成一句。
6. 断语不入页面。原文里紧挨着的吉凶断语（「父母不全」「妻妾不完」「子息凶頑」之属）
   作为上下文可以留在底本里，但矩阵与任何页面都不引用、不推断。

## 取文纪律（踩过坑之后立的）

- **一律走 `action=parse&prop=wikitext`**。`action=raw` 对分卷页常常只回模板壳，
  HTML 抓取会返回 null —— 那是**取文失败，不是内容不存在**。把取文失败当成"此书无本"
  而误删出处，是这一批真实犯过的错。
- 定位原文先用 `list=search&srsearch=insource:"短语"` 找到到底哪一页有它，再取那一页正文。
- 网络：直连维基文库不通时走本地代理 `curl -x http://127.0.0.1:7897`。

## 西方底本（批H 起，`western/` 子目录）

业主 2026-10-23 三条裁定落在这一节：① 商业站点不逐字引"限非营利／商用须授权"的底本；② 白话分层，
本站自写；③ 查不到公版古籍出处的词条一律标「近代约定／近代体系 · 非古籍」。

**载体规则（西方侧新增，比收录规则第 1 条更硬）**：只有**人工键入／校勘本**可逐字入仓 —— 实测是
Project Gutenberg 的 TXT（PGDP 校勘）。`archive.org` 的 `*_djvu.txt` 全是 OCR，**只能用来定位，不能当底本**：
同一批实测里有 `Colors→Golors`、长 s（`choofing`/`foralmoft`/`Attrologers`）、词间双空格、句中硬换行。
拿它做子串比对，失败方式是最坏的一种：看起来像有人改了原文。

**比对规则（西方篇）**：比对前两侧各自把**连续空白折叠为单空格**，除此之外逐字，改一个字母即红。
理由与东方"四库本走无标点那串"同一类 —— 源文本的排版细节不该进代码，否则一改版引用就烂。

**元数据在原有九项之外，西方篇必须再加**：载体与编号（PG 编号／archive.org identifier／owner-repo + **commit sha**）、
译者与原版出版信息、抓取日期、**整份源文件 sha256 + 本文段的字符偏移与字节数**、行尾处理声明、
以及**章节编号映射注记**（本版本的章号与通行今本不同 —— 例：Ashmand/Foulsham 1900 版的
第一卷第十六章「Mutual Configurations of the Signs」≈ 今本 I.13。**页面与文档一律不许裸写今本编号**，
要写就写"该版第几章 + 章名"）。

**正文与注者语必须分开**：注号（`[43]` 之属）在原排版里紧贴正文，但其注释文字是 19–20 世纪注者写的，
不入底本、不得引用。这条不是形式问题：相位容许度那组度数在全世界公版文本里**只存在于译者注**，
把它当古籍正文引用就是把近代约定包装成传统（详见 [[hundun-classics-sources]] 记忆与 §22）。

**近代词条清单（机检盯的就是这几个）**：`orb`／相位容许度、`Placidus` 分宫、`synastry` 合盘、`Life Path`。
它们只许出现在「近代约定 · 非古籍」那一层，不许混进原文层，也不许被写成"传统规定"。
