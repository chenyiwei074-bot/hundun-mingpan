# 八字四柱独立解读设计

日期：2026-10-26  
状态：待用户审阅  
基线：`06f3d206`

## 目标

允许用户输入已知的年、月、日、时四柱，查看仅基于这四柱的八字结构解读。复用现有四柱增强计算，不生成完整出生盘。

## 当前项目依据

- `/create` 已有四柱干支输入状态和表单，但提交时会拒绝该模式。
- `server/src/core/bazi-enrich/enrich.ts` 的 `enrichBazi(siZhu)` 已接受四柱并计算现有增强结果，可作为本功能规则结果的唯一来源。
- 现有完整排盘与大运/紫微流程依赖准确的出生日期、时刻和地点；本功能不调用该流程。

## 推荐方案

### 输入

- 在 `/create` 保留现有四柱输入控件，并将该模式标为“八字四柱解读”。
- 此模式只允许单人使用；姓名、性别、出生地和现居地输入不显示、不要求、不发送。
- 校验每柱天干地支组合属于六十甲子中的合法组合。只校验单柱合法性，不推测生日，也不静默修正四柱之间的关系。
- 提交前说明：结果根据用户输入的四柱计算；不能据此推出出生日期、真太阳时、起运或紫微命盘。

### 计算与 API

1. 前端向专用计算接口发送四柱：

   ```json
   {
     "siZhu": {
       "年": { "gan": "甲", "zhi": "子" },
       "月": { "gan": "丙", "zhi": "寅" },
       "日": { "gan": "戊", "zhi": "辰" },
       "时": { "gan": "壬", "zhi": "子" }
     }
   }
   ```

2. 后端验证四柱并调用现有 `enrichBazi`，返回原样四柱与增强计算结果；不创建或写入 `charts` / `reports` 记录。
3. 页面按需调用通用 AI 解读接口新增的 `bazi-pillars` profile。白名单仅接受四柱及已计算增强字段；AI 不重算字段、不调用紫微或大运 profile，章节通过 `factRefs` 引用实际结果字段，`sourceIds` 由服务端来源登记覆盖；无已核验古籍来源时显示“本站自研”。
4. 计算接口暂定为 `POST /api/bazi/pillars/calculate`。正式实现前由后端确认路由命名及响应字段；不得把接口实现为完整命盘生成。

### 结果页面

- 清楚展示用户输入的四柱，并标记“按输入四柱计算”。
- 展示 `enrichBazi` 已返回的五行统计、旺衰、格局、调候、干支关系、整柱和自坐字段；不得自行补算后端未返回的数据。
- 使用全站通用的“混沌自研 AI 辅助解读”卡，用户主动点击后才请求解读。
- 页面不显示紫微宫位、主星、四化、大运、流年、起运岁数或出生时地校正结果。
- 结果仅保留在当前页面状态，不提供完整命盘保存、分享海报或命盘分享链接。

## 备选方案

1. **推荐：独立计算接口 + 独立 AI profile。** 结果可复核，复用现有增强算法，和完整命盘存储及紫微链路隔离。
2. **仅本机展示四柱。** 不需要后端，但不能复用 `enrichBazi`，也无法提供可靠的结构计算与 AI 章节事实引用，不满足完整解读体验。
3. **把四柱拼造成生日后复用完整命盘。** 不采用：同一组四柱不唯一决定出生日期和时刻，会制造错误的紫微、大运与校正结果。

## 错误处理与隐私

- 非法干支组合返回可定位到年/月/日/时柱的验证错误；服务器或 AI 不可用时保留已成功计算的四柱结果并明确显示 AI 解读暂不可用。
- 原始四柱只用于本次计算和用户主动请求的 AI 解读；不带姓名、出生地、精确生日、visitorId，也不写入完整命盘或报告记录。
- 结果页面说明四柱由用户提供；系统只验证每柱是否合法，不验证其是否与某个真实出生时刻对应。

## 验收标准

- 合法四柱可返回原样四柱及现有增强结果；非法单柱被拒绝，错误位置清楚。
- 主流程未调用完整命盘创建/存储接口；结果中没有紫微、大运、起运或出生地相关字段与模块。
- AI 请求仅含允许的四柱和计算结果字段；响应引用有效 `factRefs`，没有伪造 `sourceIds`。
- AI 解读失败不隐藏规则计算结果，不把规则结果误标为 AI 生成。
- 手机与桌面均能完成输入、查看结果和触发 AI 解读；所有按钮满足现有可点击面积规范。

## 实施边界

- 本功能不修改现有八字排盘算法、紫微排盘算法、完整出生资料命盘流程或六爻算法。
- 后端需新增专用四柱计算契约和 `bazi-pillars` AI profile；前端负责表单状态、结果展示、AI 卡片和隐私文案。
- 本设计不授权新增古籍来源或 `sourceId`；没有核验来源的内容标为“本站自研”。
